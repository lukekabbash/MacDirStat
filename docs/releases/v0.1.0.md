Mac Directory Statistics v0.1.0 is the first packaged preview of the native macOS storage explorer.

## Install

1. Download the universal macOS DMG below.
2. Open it and drag **Mac Directory Statistics** to **Applications**.
3. This preview is ad-hoc signed while Apple Developer ID notarization is being configured. On first launch, Control-click the app in Applications, choose **Open**, then confirm **Open**. Later launches work normally.

Requires macOS 14 or newer. The universal build supports Apple silicon and Intel Macs.

## What is included

- Explicit Full Mac, folder, and attached-volume scans with real progress and a live treemap.
- File-type and location coloring, Map and Overview modes, capacity context, search, navigation, Quick Look, Apps, and Review.
- Persistent saved locations without repeated entries for the same source.
- Restrained themes including Soft Glass, Integrator, and Usonian.
- Source-scoped deletion controls that reset off on launch, require explicit permission, revalidate items, and always confirm before moving anything to Trash.

## Distribution note

The app is sandboxed and the release artifacts are checksum-verified. Because v0.1.0 is not yet Apple-notarized, macOS cannot show a verified developer identity on first launch. See the installation step above; no terminal command is required.
