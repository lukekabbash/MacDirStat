Mac Directory Statistics v0.1.1 brings the public macOS build up to date with the current storage workspace and its latest layout, hierarchy, and performance work.

## Install

1. Download the universal macOS DMG below.
2. Open it and drag **Mac Directory Statistics** to **Applications**.
3. This preview is ad-hoc signed while Apple Developer ID notarization is being configured. On first launch, Control-click the app in Applications, choose **Open**, then confirm **Open**. Later launches work normally.

Requires macOS 14 or newer. The universal build supports Apple silicon and Intel Macs.

## What changed

- Added explicit, compressed, read-only scan snapshots beneath each saved location.
- Added a drillable Sunburst hierarchy, saved-scan navigation, and contextual actions directly on map and hierarchy regions.
- Added purpose-made theme icons, live theme updates, refined titlebar color, and the Usonian palette.
- Added stable trailing inspectors that open only when needed and crossfade between selections without replaying the split transition.
- Consolidated scan progress into one determinate workspace bar and reduced Apps workspace entry work with bounded caches and icon loading.
- Rebuilt the dashboard header as a compact right-aligned control row for Map, Overview, snapshots, and zoom.
- Made the sidebar one calm plane with a fixed Settings footer, a bounded middle scroller, slimmer scroll chrome, and correct compact-window behavior.
- Standardized the full **Mac Directory Statistics** product name across the app, repository, and release tooling.

## Distribution note

The app is sandboxed and the release artifacts are checksum-verified. Because v0.1.1 is not yet Apple-notarized, macOS cannot show a verified developer identity on first launch. Use the Control-click installation step above; no terminal command is required.
